# Решения задач на Go

## 1. Встраивание методов структуры Human в Action
Дана структура Human (с произвольным набором полей и методов). Реализовать встраивание методов в структуре Action от родительской структуры Human (аналог наследования). Подсказка: используйте композицию (embedded struct).

## 2. Конкурентный расчет квадратов чисел
Написать программу, которая конкурентно рассчитает значения квадратов чисел, взятых из массива [2,4,6,8,10], и выведет результаты в stdout. Подсказка: запусти несколько горутин.

## 3. Постоянная запись данных с N воркерами
Реализовать постоянную запись данных в канал (в главной горутине). Реализовать набор из N воркеров, которые читают данные из этого канала и выводят их в stdout. Программа должна принимать параметром количество воркеров.

## 4. Завершение программы по Ctrl+C
Программа должна корректно завершаться по нажатию Ctrl+C (SIGINT). Выберите и обоснуйте способ завершения работы всех горутин-воркеров при получении сигнала прерывания. Подсказка: можно использовать контекст (context.Context) или канал для оповещения о завершении.

## 5. Ограничение времени работы программы
Разработать программу, которая будет последовательно отправлять значения в канал, а с другой стороны канала - читать эти значения. По истечении N секунд программа должна завершаться. Подсказка: используйте time.After.

## 6. Все способы остановки горутин
Реализовать все возможные способы остановки выполнения горутины. Классические подходы: выход по условию, через канал уведомления, через контекст, прекращение работы runtime.Goexit().

## 7. Потокобезопасная работа с map
Реализовать безопасную для конкуренции запись данных в структуру map. Подсказка: необходимость использования sync.Mutex. Проверьте работу кода на гонки (go run -race).

## 8. Управление битами числа
Дана переменная типа int64. Разработать программу, которая устанавливает i-й бит этого числа в 1 или 0. Пример: для числа 5 (0101) установка 1-го бита в 0 даст 4 (0100).

## 9. Конвейер чисел
Разработать конвейер чисел. Даны два канала: в первый пишутся числа x из массива, во второй - результат операции x*2. После этого данные из второго канала должны выводиться в stdout.

## 10. Группировка температур
Дана последовательность температурных колебаний: -25.4, -27.0, 13.0, 19.0, 15.5, 24.5, -21.0, 32.5. Объединить эти значения в группы с шагом 10 градусов.

## 11. Пересечение множеств
Реализовать пересечение двух неупорядоченных множеств (например, двух слайсов). Пример: A = {1,2,3}, B = {2,3,4} → {2,3}.

## 12. Создание множества строк
Имеется последовательность строк: ("cat", "cat", "dog", "cat", "tree"). Создать для неё собственное множество. Ожидается: {"cat", "dog", "tree"}.

## 13. Обмен значений без временной перемени
Поменять местами два числа без использования временной переменной. Подсказка: примените сложение/вычитание или XOR-обмен.

## 14. Определение типа переменной
Разработать программу, которая в runtime способна определить тип переменной (int, string, bool, chan). Подсказка: используйте switch v.(type).

## 15. Анализ работы со строками
Рассмотреть код с созданием большой строки и присваиванием подстроки. К каким негативным последствиям может привести? Приведите корректный пример реализации.
```
var justString string

func someFunc() {
  v := createHugeString(1 &lt;&lt; 10)
  justString = v[:100]
}

func main() {
  someFunc()
}
```

## 16. Быстрая сортировка
Реализовать алгоритм быстрой сортировки массива встроенными средствами языка. Можно использовать рекурсию.

## 17. Бинарный поиск
Реализовать алгоритм бинарного поиска встроенными методами языка. Функция должна принимать отсортированный слайс и искомый элемент.

## 18. Потокобезопасный счетчик
Реализовать структуру-счётчик, которая будет инкрементироваться в конкурентной среде. По завершению программы вывести итоговое значение.

## 19. Реверс строки
Разработать программу, которая переворачивает подаваемую на вход строку. Учесть Unicode символы (русские буквы, emoji).

## 20. Реверс порядка слов
Разработать программу, которая переворачивает порядок слов в строке. Пример: "snow dog sun" → "sun dog snow".

## 21. Паттерн Адаптер
Реализовать паттерн проектирования «Адаптер» на любом примере. Продемонстрировать на простом примере в Go.

## 22. Операции с большими числами
Разработать программу, которая перемножает, делит, складывает, вычитает две числовых переменных a, b, значения которых > 2^20.

## 23. Удаление элемента из слайса
Удалить i-ый элемент из слайса. Продемонстрировать корректное удаление без утечки памяти.

## 24. Расстояние между точками
Разработать программу нахождения расстояния между двумя точками на плоскости. Точки представлены в виде структуры Point.

## 25. Реализация функции sleep
Реализовать собственную функцию sleep(duration) аналогично time.Sleep, но с блокировкой текущей горутины.

## 26.Уникальные символы в строке
Разработать программу, которая проверяет, что все символы в строке встречаются один раз (т.е. строка состоит из уникальных символов).
Вывод: true, если все символы уникальны, false, если есть повторения. Проверка должна быть регистронезависимой, т.е. символы в разных регистрах считать одинаковыми.
